# Timely – نظام إدارة المواعيد الطبية

## نبذة عن المشروع

Timely هو نظام لإدارة المواعيد الطبية في المستشفيات والعيادات يهدف إلى تسهيل عملية استعراض الأقسام الطبية والخدمات المتاحة وحجز المواعيد بالإضافة إلى تنظيم وإدارة البيانات المرتبطة بالمرضى والأطباء والموظفين

يوفر النظام منصة موحدة لإدارة العمليات الأساسية للمنشأة الطبية، بدءاً من إدارة الأقسام والخدمات الطبية مروراً بتنظيم المواعيد وصولاً إلى متابعة المدفوعات والفواتير والتقييمات

يتكون المشروع من نظام (Backend) مبني باستخدام ASP.NET Core وتطبيق للهواتف الذكية مبني باستخدام Flutter ويتواصل التطبيق مع  Backend من خلال واجهات REST API

## الوظائف الرئيسية

- ادارة المستخدمين: تسجيل الدخول وإدارة حسابات المستخدمين
- ادارة الأقسام الطبية: عرض الأقسام والتخصصات الطبية وتنظيم بياناتها
- ادارة الأطباء والموظفين: ربطهم بالأقسام والوظائف
- ادارة الخدمات الطبية: عرض الخدمات المتاحة وإدارة تفاصيلها وأسعارها
- حجز المواعيد: اختيار التاريخ والوقت المناسب وإدارة الحجوزات
- إدارة العملاء والمرضى: حفظ بيانات العملاء وتنظيم سجلاتهم
- إدارة المدفوعات: تسجيل وإدارة بيانات المدفوعات المرتبطة بالمواعيد
- إدارة الفواتير: حفظ وتنظيم بيانات الفواتير
- التقييمات: إدارة تقييمات الخدمات وتجربة المستخدم
- الملف الشخصي: عرض بيانات المستخدم وإدارة معلومات الحساب

## هيكل المشروع

تم تنظيم مشروع Backend إلى مجموعة من المكونات، بحيث يتولى كل مكون مسؤولية محددة داخل النظام:

| المجلد | المسؤولية 
 Controllers  استقبال طلبات HTTP وتنفيذ نقاط الاتصال الخاصة بالنظام
 Models  تعريف الكيانات ونماذج البيانات
 DTOs  تنظيم البيانات المتبادلة بين أجزاء التطبيق
 Data  إعداد الاتصال بقاعدة البيانات وإدارة DbContext
 Repositories  تنفيذ عمليات الوصول إلى البيانات
 Service  تنفيذ العمليات والخدمات المرتبطة بمنطق التطبيق
 Interfaces  تعريف العقود والواجهات الخاصة بالخدمات والمستودعات
 Migrations  تتبع تغييرات بنية قاعدة البيانات
 Views  واجهات تطبيق الويب

## البنية المعمارية

يعتمد النظام الخلفي حالياً على تنظيم متعدد الطبقات (Layered Architecture)، من خلال فصل Controllers عن Services وRepositories وطبقة الوصول إلى البيانات باستخدام Entity Framework Core

يساعد هذا التنظيم على فصل المسؤوليات وتقليل الترابط بين أجزاء النظام وتسهيل صيانة الكود وتطويره مستقبلاً.

## أهداف المشروع

- تسهيل إجراءات حجز المواعيد الطبية
- تنظيم بيانات الأقسام والأطباء والخدمات الطبية
- توفير إدارة مركزية للمواعيد والعملاء
- تنظيم سجلات المدفوعات والفواتير
- بناء نظام قابل للتطوير والصيانة وإضافة وظائف جديدة مستقبلاً

## حالة المشروع

المشروع قيد التطوير وتخضع بعض الوظائف والتكاملات لمراحل إضافية من التنفيذ والاختبار والتحسين
